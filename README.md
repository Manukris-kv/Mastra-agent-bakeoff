# Mastra Bake-Off — Dev Daily Assistant

Workshop repo for the agent-bakeoff checkpoint arc — see [`AGENT_CHECKPOINTS.md`](AGENT_CHECKPOINTS.md) for the full plan.

This branch (`boilerplate`) is a plain, unmodified `npm create mastra@latest`
scaffold — the starting point before checkpoint-1 begins. Check out
`checkpoint-1` through `checkpoint-7` to see the assistant built up one
concept at a time.
